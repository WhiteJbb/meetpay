# 작업: meetpay 정산 내용을 단톡방용 글로 복사하는 버튼 추가

objective: 모임 정산 탭과 열람 전용 결과 화면에서 모임 이름, 이체별 금액·받는 계좌,
열람 전용 결과 링크를 한 번에 글로 복사해 단톡방에 붙여 넣을 수 있게 한다.

AC-1: 모임 화면 정산 탭과 /r/[token] 열람 전용 결과 화면 모두 이체가 있으면 '정산 내용 복사'
버튼을 표시하고 실제 클릭으로 클립보드에 같은 정산 내용을 쓴다.
AC-2: 복사되는 텍스트의 첫 줄은 모임 이름, 다음은 이체마다 한 줄씩 '민수 → 지영 12,000원'
형태이며 화면의 이체 순서·대상·금액과 일치한다. 받는 계좌가 있으면 해당 이체 줄 끝에 정확한
계좌를 붙이고 없으면 계좌 표기를 생략한다. 여러 이체와 계좌 등록/미등록 혼합 사례를 검증한다.
AC-3: 복사 텍스트 마지막 줄은 해당 모임의 열람 전용 결과 절대 URL이다. 두 진입 화면 모두 편집
링크가 아닌 /r/[viewToken]을 사용하며 열람 전용 화면의 기존 편집 불가 동작을 보존한다.
AC-4: 이체가 없는 경우 두 화면 모두 정산 내용 복사 버튼이 숨겨지며 기존 빈 정산 안내와 결과
링크 복사는 유지된다.
AC-5: 복사 성공 피드백과 클립보드 거부/사용 불가 시 실패 안내 및 재시도를 브라우저에서 확인한다.

해당 화면 캡처를 남긴다.
AC-6: 등록 검사 lint와 build가 통과하고 추가 기능 테스트 및 생성→지출→정산→결과 공유 핵심
회귀를 검증한다. 검증 결과와 사용자의 요청에 따른 변경을 문서에 기록하며 비밀값 검사와 코드

## 2026-11-05 — task-20261105-002 r3 (B 데스크톱 레이아웃 수정)

계약 피드백 원문:

- 사용자가 B 구현에 추가 수정 진행을 명시적으로 승인했다: 데스크톱에서 좌우 높이 균형을 맞추되 오른쪽 지출 조작과 송금 결과를 한 화면에 함께 보여 준다.
- 좌우 시작 위치와 시각적 높이 균형을 맞추고 장부의 폭·간격·배치를 조절하여 일반 데스크톱 1440×900 및 1366×768 첫 뷰포트에서 지출 체크박스 전체와 마지막 송금 결과가 스크롤 없이 동시에 보이도록 한다. 왼쪽을 빈 공간으로 늘리는 것만으로 해결하지 않는다. 글자를 과하게 줄이거나 정보를 자르거나 숨기지 않고 장부 내부에 별도 스크롤을 넣지 않는다. 창이 작거나 확대되면 잘림 없이 문서 스크롤을 허용한다.
- 모바일은 자연스러운 세로 배치를 유지하며 가로 넘침·잘림·겹침이 없어야 한다. 기존 B의 예시 지출 토글·재계산·초기화·빈 상태·새 모임 만들기 동작과 기존 앱 기능을 유지한다.
- 브라우저에서 1440×900, 1366×768, 모바일 390px을 확인하고 캡처와 실제 요소 경계 측정으로 데스크톱 조작/송금 결과가 첫 화면에 함께 들어오는 근거를 남긴다. 토글과 초기화 후에도 유지되는지 확인한다. 등록된 검사·비밀값 검사·리뷰를 다시 통과한다. 범위는 이 레이아웃 수정에 한정하고 보고서의 별도 열린 문제나 정산 알고리즘은 임의로 변경하지 않는다.
